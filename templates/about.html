Abstract

This academic tool enables students to explore, compare, and analyse five fundamental multiple‑access techniques used in wireless communication. By entering system parameters, the backend computes deterministic performance metrics based on textbook models, visualises results with interactive charts, and produces a PDF report.

Introduction

Wireless networks must share limited spectrum among many users. Techniques such as FDMA, TDMA, CDMA, OFDMA, and SDMA provide different ways to allocate resources, each with trade‑offs in efficiency, interference, and implementation complexity.

Problem Statement

Students often struggle to understand how these techniques differ quantitatively. Existing textbooks provide qualitative descriptions but lack an interactive, computational sandbox.

Objectives

  • Provide clear definitions and visual explanations of each technique.
  • Allow side‑by‑side comparison with deterministic calculations.
  • Visualise performance metrics through responsive charts.
  • Generate a downloadable PDF summarising the analysis.

Methodology

The application is built with Flask (backend), Bootstrap 5 (frontend), Chart.js (charts), NumPy (math), and ReportLab (PDF). All calculations are performed server‑side using Shannon capacity and technique‑specific efficiency factors.

Modules

  • Learn Techniques – educational content.
  • Module 1 – deterministic side‑by‑side comparison tables.
  • Module 2 – user‑driven performance analysis with charts.
  • Results Dashboard – tabular summary and PDF export.
  • Analysis History – persistent SQLite storage.

SDG Contribution

Supports Quality Education (SDG 4) by providing an interactive learning platform for engineering students.

Conclusion

The tool demonstrates how theoretical models translate into concrete performance numbers, helping students grasp the impact of multiple‑access choices on wireless system design.

References

  • Goldsmith, "Wireless Communications", Cambridge University Press, 2005.
  • Rappaport, "Wireless Communications: Principles and Practice", 2nd ed., 2002.
  • IEEE 802.11 and 802.16 standard documents.
